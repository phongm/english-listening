# 每日英语听力 · 随播双语字幕

在「每日英语听力」里照常播放，屏幕底部一条**透明、始终置顶**的字幕条会**按播放进度自动**显示当前英文句和中文译文。
英文里每个单词带细下划线，悬停即可看该词的释义，不用逐句点、不用复制、不用切 App。

这个仓库原来的用途是抓 VOA 课文做双语对照；现在主链路换成了随播字幕，原来的工具作为备用保留。

---

## 一、它怎么工作（只读，不破解）

- 「每日英语听力」是 Electron 应用。打开一篇课文后，带逐句时间轴的明文页面会落在
  `~/Library/Application Support/ting_en/ting/tmp/temp/index.html`，每句带 `data-startTime` / `data-endTime`。
- 启动时给 App 加一个**只监听 127.0.0.1** 的调试端口（9333），通过它读播放器 `<video>` 的
  `currentTime`、`duration`、`paused`，按时间轴找到当前句。
- 绑定课文后在后台把整篇课文交给微软 Edge 的免费翻译端点预翻译，按句缓存到
  `~/English/ting-cache/<课文UUID>.json`；显示时直接查表，所以同一篇第二次打开是秒出。
- 本地 HTTP + SSE（127.0.0.1:8787）把状态推给置顶字幕条（Swift NSPanel + WKWebView）。
- 单词释义：当前句和下一句里的生词会复用同一个免费端点批量机翻，缓存在
  `~/English/ting-cache/words.json`；鼠标悬停时再按需查有道词典的公开接口，补上词性和多条释义，
  结果缓存在 `~/English/ting-cache/dicts.json`。机翻先秒出，词典结果到了再替换。

明确不做的事：不破解 App 的加密缓存、不导出或下载音频、不使用 App 的 VIP 精校译文、
不修改 App 包、调试端口只开在本机回环地址。

## 二、装（只做一次）

前置：机器上有 Node.js（`brew install node` 或 nodejs.org 的 LTS 安装包）。
置顶字幕条需要 Xcode 命令行工具（`xcode-select --install`）；没有也能装，只是会退回用浏览器窗口。

1. 把仓库放到任意位置。
2. 双击 **`install.command`**。

安装器会：

- 找 `node`，试本机代理 `http://127.0.0.1:7890`
- 写 `~/English/config` 和 `~/English/ting-sync.conf`（都不进仓库，换机器重新生成）
- 生成稳定入口 `~/English/run.sh` 和兼容软链 `~/scripts/*.mjs`
- 在 `~/Applications` 生成 4 个双击 App：
  **每日英语听力·同步**（启动器）、**每日英语听力·同步字幕**（置顶条）、
  **译剪贴板**、**抓课文**
- 跑翻译自检和随播字幕自检（后者需要 App 里打开过一篇课文）

## 三、日常用

1. 双击 **「每日英语听力·同步」**。
   - App 没开：直接带同步端口启动。
   - App 已用普通方式开着：会问一次是否重启。重启只中断当前播放，**播放进度会自动恢复**。
2. 在 App 里播放任意带逐句文本的课文。字幕条会自动跟着进度走。
3. 字幕条操作：
   - 整条字幕（工具按钮除外）都可以按住拖动到屏幕任意位置；位置会记住，拖出屏幕时会自动留出可抓回的边。
   - 英文每个单词带细下划线，鼠标悬停（或点一下）看这个词的译法和词性；词典结果没回来前先显示机翻。
   - 工具栏：上一句 / 重听、**暂停 / 继续原音频**、下一句、**双语 / 原文 / 译文 / 逐词**、**倍速**、**背景浓度**、**设置**、字号、隐藏。
   - 设置现在从 macOS 菜单栏的 `captions` 图标 →「设置…」打开独立设置窗口；字幕条上的齿轮也会打开这个窗口，不再被字幕条高度裁住。
   - 齿轮按钮是开关：第一次点击打开设置窗口，再点一次直接关闭；设置窗口本身用 macOS 原生关闭按钮或 `Esc` 关闭。
   - 默认全局快捷键：`⌘B` 显示 / 隐藏字幕条，`⌘⇧S` 显示 / 隐藏设置，`⌃⌥Space` 暂停 / 继续，`⌃⌥←/→` 上一句 / 下一句，`⌃⌥M` 切显示模式，`⌃⌥B` 切背景，`⌃⌥[/]` 降 / 升倍速，`⌃=/-` 字号。
   - 设置里有「快捷键」区，点击任意快捷键按钮后按下新组合即可自定义；所有快捷键可重置为默认。
   - 快捷键只要包含 `⌘`、`⌃` 或 `⌥`，就会全局生效；没有修饰键的快捷键只在字幕条获得焦点时生效。
   - 字幕过长时会自动增高，最多到 320px；仍然放不下时会自动轻微缩小字号，避免截断。
   - 「设置」里可以改窗口高度、显示模式、背景浓度、倍速、悬停单词是否暂停、离开后是否继续、单词下划线、歌词进度、工具栏常显、进度条、暂停变暗，并导出 SRT / Markdown。
   - 倍速支持 0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x；「记住并应用倍速」开启后，下次打开字幕条会自动恢复到上次倍速。
   - 悬停单词默认会暂停原音频，移开 0.35 秒后自动继续；不想要可在设置里关掉。
   - 点击英文单词会固定词典，可复制单词、复制整句、收藏到生词本；再点一次或按 Esc 取消。
   - 歌词进度：用文字从暗到亮表示当前句播放进度，默认开启；关闭后恢复线性进度条。
   - 快捷键：空格暂停/继续，←/→ 切句，M 切模式，B 切背景，[ / ] 降/升倍速，+ / - 字号，, 设置，Esc 收起。
   - 设置里可导出当前课文：SRT（带时间轴双语）或 Markdown（双语列表）。
   - 单词词典浮层不再靠悬停时动态扩窗，避免抖动；默认窗口高度 200px，可在设置里选 168 / 200 / 240。
   - 背景默认半透明（能看清又不完全挡住画面），可切到轻、强或无；显示模式和背景浓度都会记住。
   - 字幕条获得焦点时可用空格暂停 / 继续 App 播放，左右方向键切句。
   - 点 X 只是隐藏，不会退出程序；菜单栏 `captions` 图标、双击「每日英语听力·同步」或重新打开「每日英语听力·同步字幕」都会把它重新显示出来。
   - 菜单栏的 `captions` 图标可以显示 / 隐藏 / 重新载入 / 退出字幕条。
   - 关掉字幕条不影响 App 播放。

暂停时字幕条会变暗并显示「已暂停」。切换课文会自动换文本；拖动 App 的进度条跳转，
译文会从新位置继续取（没译过的句子会现场补译）。

## 四、第一次用需要知道

- 只有**带逐句时间轴**的课文才能跟（Podcast、精听课文一类）。纯音频无文本、或视频课，可能显示「等待课文页」。
- 新课文第一次播放时，译文是边播边翻的：整篇通常十几秒到一分钟翻完，之后写入缓存，重听秒出。
- 翻译端点被限流时会显示「译文中…」，服务会自动重试；已经翻过的句子不受影响。
- 字幕条默认是半透明深色底，兼顾视频画面和文字清晰度；可用「背景」按钮切到轻、强或全透明。
- 英文单词的释义是**按词**给的，不结合上下文；整句的中文才是语境翻译。有道词典接口不通时只显示机翻。
- 「逐词」会保留中文翻译的自然语序，只给对应片段画上同色下划线；它不追求把中文重排成英文语序。
- 单词悬停框有深色底，是为了压在视频上也看得清；它只在鼠标移到单词上时出现。

## 五、命令行（可选）

```bash
~/English/run.sh ting-sync-start      # 带同步端口启动 App（未运行时）+ 起服务 + 开字幕条
~/English/run.sh ting-sync-launch     # 先退出 App 再带同步端口重启（App 已普通启动时）
~/English/run.sh ting-sync-state      # debug-ok / running-no-debug / not-running
~/English/run.sh ting-sync-stop       # 停同步服务和字幕条，不影响 App 播放
~/English/run.sh ting-sync-follow     # 只在终端打印当前句和译文
~/English/run.sh ting-sync-probe      # 输出课文 / 播放器 / 缓存的诊断 JSON
~/English/run.sh ting-sync-selftest   # 自检课文解析与翻译通道
```

配置：

- `~/English/config`：`TING_APP`、`TING_CDP_PORT`（默认 9333）、`TING_WEB_PORT`（默认 8787）
- `~/English/ting-sync.conf`：课文页路径、端口、缓存目录、`TR_PROXY`
- 日志：`~/English/logs/ting-sync.log`；字幕条自己的渲染日志在 `~/English/logs/overlay.log`（记录 2x/1x 渲染比例和窗口尺寸）

## 六、诊断

| 现象 | 先看什么 |
| --- | --- |
| 字幕条提示「请用「每日英语听力·同步」图标启动 App」 | App 在跑但没开同步端口。退出 App 后双击同步图标；或运行 `ting-sync-launch` |
| 双击同步图标后没有字幕条 | 菜单栏 `captions` 图标 → 显示；或 `ting-sync-stop` 后重开；看 `~/English/logs/ting-sync.log` |
| 点了字幕条的 X 后找不到 | 它只是隐藏：点菜单栏 `captions` → 显示，或重新双击「同步」/「同步字幕」图标 |
| 一直「等待音频开始播放」 | 在 App 里真正开始播放一篇带文本的课文 |
| 一直「正在切换课文…」 | 课文页和音频对不上，等 App 自己切完；不行就退出课文重进 |
| 「译文中…」一直不消失 | 网络或代理问题。跑 `ting-sync-selftest`；在 `ting-sync.conf` 里设 `TR_PROXY` |
| 解析句数为 0 | App 内部结构可能变了，跑 `ting-sync-probe` 确认；见下面的边界 |
| 端口被占用 | 改 `~/English/config` 与 `ting-sync.conf` 里的 9333 / 8787，然后 `ting-sync-stop` 再启动 |

## 七、已知边界

- 依赖 App 的内部实现（tmp 课文页、`<video>` 元素、调试端口）。App 大版本更新后可能失效，需要重新适配。
- 不提取音频、不导出缓存、不解密离线包；只翻译自用，不传播。
- 翻译走免费公开端点，没有 SLA，机翻质量低于官方精校。App 内的 VIP 译文该付费仍付费。
- 字幕条与 App 是两套进程：App 退出后字幕条会显示「等待每日英语听力启动…」，
  用同步图标重开 App 即可自动恢复。

## 八、附带的 VOA 离线链路（备用）

原来的用法仍然可用：抓 VOA 课文、下 MP3、出双语对照表。

**VOA Learning English**（`learningenglish.voanews.com`）材料属公有领域，音频和全文可自由下载、翻译、自用。
2025-03-14 行政令裁撤 USAGM 后 VOA 停更，但三级课和 Let's Learn English 等作为冻结存档仍可访问。

| 想做什么 | 怎么做 |
| --- | --- |
| 翻译一句 | 任意 App 里选中英文 → `⌘C` → 双击 **译剪贴板** → 点「复制译文」才覆盖剪贴板 |
| 学一整篇 VOA | 复制课文链接 → 双击 **抓课文** → 自动下音频、生成双语对照表并打开 |

```bash
~/English/run.sh tr-clipboard          # 翻译剪贴板
~/English/run.sh tr "some english"     # 直接翻译
~/English/run.sh grab "<课文URL>"      # 抓课文 + 下音频
~/English/run.sh grab-clipboard        # 用剪贴板链接抓课文并出对照表
~/English/run.sh batch 你的字幕.lrc     # 任意 lrc/srt/vtt/txt 出双语对照
~/English/run.sh selftest              # 自检 node / 路径 / 翻译通道
```

产物在 `~/English/voa/`：`<编号>.txt`、`<编号>.mp3`、`<编号>.对照.md`。

选源时排除掉的候选：`americanenglish.state.gov`（已迁站，是教师资源）、`elllo.org`（主音频只在
SoundCloud 嵌入里）、BBC / archive.org（有版权，不做批量下载）。

## 九、仓库里有什么

```
bin/ting-sync.mjs           随播字幕核心：课文解析、播放进度、预翻译、单词释义/词典/逐词对照、播放控制、缓存、SSE 服务
bin/lib/edge-translate.mjs  字幕专用的免费翻译通道（批处理）
overlay/bar.html            字幕条页面（透明、单词下划线/悬停释义、工具栏、状态提示）
overlay/settings.html       独立设置窗口页面（显示、播放、快捷键、导出）
overlay/Overlay.swift       置顶透明面板（NSPanel + WKWebView），由 install.command 编译
apps/sync.applescript       「每日英语听力·同步」启动器源码
apps/*.applescript          译剪贴板 / 抓课文 的源码
bin/voa-grab.mjs            抓 VOA 课文：抽正文切句 + 下 MP3
bin/bilingual-subtitle.mjs  任意 lrc/srt/vtt/txt → 双语对照 md / 双语 lrc
bin/tr.mjs                  剪贴板/管道/参数 → 译文
bin/run.sh                  统一入口（上面的命令都走它）
install.command             双击安装 + 自检，幂等
```
